版本：0.14.0

这是手机当前安装版本对应的源码。App 为 Java 原生 Android 程序，无 Gradle/Maven 依赖。

当前功能
- 手机内直接登录南京财经大学教务，由本人输入账号及验证码。
- 课程存储在手机本地，断网可查看；通过 App 手动更新教务课表。
- 独立桌面组件，不依赖日历、ICSx⁵ 或作者服务器。
- 固定日期表头、滚动周课表、左侧时间轴、整点横线、21:00 末端刻度。
- 课程块保持完整，可点击查看详情；支持切周和定位当前时段。
- 早八前从早课开始，课表结束后定位末段；不额外补大块底部占位。
- 不提供 JSON 文件导入导出、后台教务自动同步或课前通知。

构建
本机现有 JDK、SDK 路径已作为 build.ps1 默认参数，可直接运行：
  .\build.ps1
默认生成 build\nufe-local.apk。
也可以指定工具目录和安装包输出位置：
  .\build.ps1 -Jdk 'JDK 17目录' -Sdk 'Android SDK目录' -Output 'APK绝对路径'
需要 SDK platform android-35 和 build-tools 35.0.0。

覆盖更新
保持包名 cn.local.nufeschedule 及 local-signing.p12 不变。
每次发布时提高 AndroidManifest.xml 的 versionCode 并修改 versionName。
覆盖安装示例（使用 SDK platform-tools 的 adb）：
  adb install -r --no-incremental --user 0 build\nufe-local.apk
手机的系统安装确认需要本人允许；不要卸载旧版，否则会删除旧版的本地数据。
此签名文件是构建身份，公开分享源码时不必包含它；.gitignore 已将它排除。

兼容与限制
最低 Android 8.0；完整分段滚动网格和当前时段定位使用 Android 12+ RemoteViews API。
旧系统保留整张周课表的滚动回退显示，定位功能有限。
目前仅在用户连接的 vivo 手机上持续调试；没有进行多品牌真机验证。
Android 原生组件滚动接口只能保证目标时段进入视野，不保证所有桌面都严格像素对齐到顶部。
学校页面结构变化、校园网络限制或登录过期可能需要重新导入或调整 school-import.js。
没有绕过学校证书校验，没有保存学校密码，没有将课表发往开发者服务器。
